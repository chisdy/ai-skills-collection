# 意图问卷与合规话术

## 1. 合规确认（一句话，不做法律说教）

开场：

> 复刻会采集这个站的页面结构、样式与功能特征。用途是学习 / 重建自己的站 / 已授权复刻 / 竞品分析中的哪一种？采集全程不会在对方站点提交任何数据。

按回答处理：

| 回答 | 处理 |
|---|---|
| 学习 / 练习 | 继续；交付时提醒不要把原站素材（图、文案、Logo）用于公开发布 |
| 自己的站 | 继续；问是否有后台 URL 与账号（admin IA 可实采）；确认是自有站点后子技能可开 `--allow-writes` |
| 已授权 | 继续；README 合规声明写"经授权" |
| 竞品分析 | 继续；说明产出是功能与视觉分析，素材不复用 |
| 要上线一个"一样的"站 | 缩范围：功能架构与布局可以借鉴，品牌 / 文案 / 图片 / Logo 必须重做；用户坚持照搬则拒绝素材部分 |
| 要绕过登录 / 付费 / 验证码 | 拒绝该部分；登录只能用户自己完成 |
| 目标站 robots.txt Disallow 且非所有者 | 告知风险；用户决定后继续或改为内联浏览器人工浏览采集 |

## 2. 问卷措辞（一次问完）

> 1. 目标 URL？有特别要或不要的页面吗？站点大概多大？
> 2. 用途（上面已答可跳过）。
> 3. 能登录吗？有后台地址吗？是你自己的站点或测试环境吗？
> 4. 视口：默认 1440 / 768 / 390 三档，需要改吗？
> 5. 页面代码用什么栈：静态 HTML/CSS/JS、React 19 + Tailwind v4、还是 Vue 3.5 + Tailwind v4？图标库默认 Lucide，动画默认 CSS + IntersectionObserver，要换吗？
> 6. 产物放在当前项目的 `clone-package/` 可以吗？

用户不想回答某项时用默认值并在 README 里注明"默认"。

## 3. 答案如何传给子技能

委派时在给子技能的任务描述里写明（子技能的 SKILL.md 规定"主控传来的答案不重复问"）：

```
已由 website-clone 主控确认：
- 用途：竞品分析（合规已确认）
- URL：https://example.com；页面清单：clone-package/site-map.json（N 页，类型分布 …）
- 账号：无 / 有（用户会在内联浏览器登录）；后台 URL：无 / https://…
- 自有 / 测试站点：否（不要开 --allow-writes）
- 视口：1440 / 768 / 390
- 技术栈：React 19 + Tailwind v4；图标：Lucide；动画：CSS + IntersectionObserver
- 输出目录：clone-package/docs/（functional）/ clone-package/visual/（visual）
```

视觉子技能额外传：页面范围 = PRD §6 中 Must / Should 且非登录墙的页面（可写成一个 `site-map.json` 子集文件 `clone-package/visual/pages.json`）。

## 4. 什么时候停下来

- 合规确认得到"上线冒充"或"绕过付费墙"这类答案
- 子技能缺失（完成发现后停下给安装命令）
- `discover_site.py` 只发现首页且 `--render` / 内联浏览器都不可用（告知只能做单页）
- 用户中途改口只要一半（交给对应子技能，主控退出）
