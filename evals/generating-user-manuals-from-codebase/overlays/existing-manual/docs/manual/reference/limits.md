# 限制汇总

下表列出使用 Lumen 素材库时会遇到的限制，以及超出时界面上的表现。

| 项目 | 限制 | 在哪里能看到 | 超出时 |
|---|---|---|---|
| 导入文件类型 | 仅 CSV、XLSX | 导入对话框「支持 CSV、XLSX，单个文件不超过 5 MB」 | 提示「文件类型不支持，请上传 CSV 或 XLSX」 |
| 单个文件大小 | 不超过 5 MB | 导入对话框同上 | 提示「文件超过 5 MB」 |
| 素材名称 | 必填，最多 60 个字符 | 输入框到 60 字后无法继续输入 | 留空时提示「素材名称不能为空」 |
| 界面语言 | 仅简体中文 | **设置** › **界面语言** 下拉框灰显 | — |
| 通知设置保存 | 仅当前会话内有效 | — | 刷新页面后恢复默认 |
