# 修改通知设置

在 **设置** 页可以决定素材处理完成后是否通知你。所有角色都能修改自己的这项设置。

## 开始之前

- 任意角色都可以进入 **设置** 页，无需额外权限。

## 开启或关闭完成通知

1. 在左侧菜单点击 **设置**。
2. 勾选或取消勾选 **素材处理完成时通知我**。
3. 点击 **保存**。

**结果：** 页面右上角出现「设置已保存」提示。

## 界面语言

**界面语言** 一项当前固定为 **简体中文**，下拉框不可更改。本版本没有其他语言可选。

## 出现问题时

- **刷新页面后设置恢复了：** 通知设置只在当前会话内生效，刷新后会回到默认值；这是当前版本的限制，见[限制汇总](../../reference/limits.md)。
