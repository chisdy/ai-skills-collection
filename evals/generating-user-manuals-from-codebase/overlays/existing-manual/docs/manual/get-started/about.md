# 关于本手册

本手册介绍 Lumen 素材库 0.3.0 的使用方法，面向日常使用它的查看者、编辑者，以及负责成员管理的管理员。

## 适用范围

- 覆盖：概览、素材的导入 / 查看 / 删除、成员列表、通知设置。
- 不覆盖：邀请成员（当前版本按钮不可用）、系统部署与账号开通。

## 阅读约定

- 加粗文字（如 **导入文件**）是界面上按钮或菜单的原文。
- 「」内是界面提示或对话框里的原文。
- 标题旁的 [管理员] 表示只有管理员能看到该功能。
- > **注意** 段落出现在不可逆操作之前，请先读完再点。

## 角色一览

| 角色 | 界面显示 | 能做什么 |
|---|---|---|
| 查看者 | 查看者 | 查看素材 |
| 编辑者 | 编辑者 | 查看、导入素材 |
| 管理员 | 管理员 | 查看、导入、删除素材，查看成员 |

当前角色显示在页面右上角「当前角色」旁。
